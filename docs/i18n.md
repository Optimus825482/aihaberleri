# i18n – Merkezi Çeviri Kılavuzu

**Rapor önerisi:** Çevirileri tek yapıda (`messages/tr.json`, `messages/en.json`) toplamak ve next-intl ile tutarlı kullanmak.

## Yapı

- **Konum:** `src/messages/tr.json`, `src/messages/en.json`
- **Yükleme:** `src/i18n.ts` → `getRequestConfig` ile locale’e göre `./messages/${locale}.json` import edilir
- **Diller:** `tr` (varsayılan), `en` (path prefix `/en`)

## Kurallar

1. **Yeni metin eklerken** önce `messages/tr.json` ve `messages/en.json` içinde uygun namespace altında key ekleyin (örn. `common.loading`, `article.readMore`).
2. **Bileşenlerde** sabit Türkçe/İngilizce string yazmayın; `useTranslations('namespace')` ile `t('key')` kullanın.
3. **Namespace’ler** mevcut yapıyı takip etsin: `common`, `navigation`, `footer`, `article`, `contact`, `search`, `admin` vb.
4. **Key isimlendirme:** camelCase, anlamlı (örn. `readMore`, `noResults`).
5. **Eksik çeviri:** Bir dilde key yoksa diğer dildeki değer veya key’in kendisi kullanılabilir; mümkünse her iki dosyada da aynı key’i doldurun.

## Örnek

```tsx
// Önerilen
import { useTranslations } from 'next-intl';
const t = useTranslations('common');
return <button>{t('readMore')}</button>;

// Kaçınılacak
return <button>Devamını Oku</button>;
```

## Dosya eşleşmesi

`tr.json` ve `en.json` aynı key ağacına sahip olmalı; yeni key eklerken her iki dosyayı da güncelleyin.
